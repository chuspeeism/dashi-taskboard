# Product

## Register

product

## Users

Codex and ChatGPT users who manage long-running development, research, and content workflows across many conversations. They need to see task state, progress, history, and next actions without searching through chat noise.

## Product Purpose

Dashi Taskboard turns Codex conversations into a durable task workflow. It adds a taskboard entry to the Codex sidebar, organizes work by status and project, keeps a feature-level history across conversations, exposes real execution progress, and supports low-touch automation. Success means users can identify what is waiting, active, blocked, ready for review, or complete at a glance and move work forward safely.

## Brand Personality

Calm, precise, native. The interface should feel at home in current macOS and iOS product surfaces, remain readable during daytime use, and follow the Codex host theme without becoming visually noisy.

## Anti-references

- Dark-only interfaces that force nighttime styling during daytime use.
- Flat generic SaaS dashboards with weak hierarchy or indistinguishable panels.
- Decorative glass effects on task content, arbitrary shadows, and oversized rounding.
- Popovers clipped by navigation or scroll containers.
- Status columns that visually merge into surrounding chrome because spacing and surface boundaries are unclear.

## Design Principles

1. Make task state and progress legible in one glance.
2. Use predictable Apple-style hierarchy, spacing, focus, and interaction patterns.
3. Let navigation and transient overlays use restrained material effects; keep task content on solid surfaces.
4. Preserve context across theme changes and conversations.
5. Reduce manual coordination while keeping state changes explicit and recoverable.

## Accessibility & Inclusion

Target WCAG AA for text and interactive controls. Support keyboard navigation, visible focus, reduced motion, light and dark host themes, semantic dialogs and popovers, and layouts without document-level horizontal overflow.
